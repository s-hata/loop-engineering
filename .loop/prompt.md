# Codex Instructions

`.loop/task.md` を読み、そこに書かれているタスクを実装してください。

まず既存コードとテストを確認してください。

## Rules

- タスクの達成に必要な変更だけを行ってください
- 既存の正常な動作を壊さないでください
- Acceptance Criteria を満たすテストを追加してください
- `.loop/task.md` は変更しないでください
- `.loop/prompt.md` は変更しないでください
- `.loop/verify.sh` は変更しないでください
- `.loop/run.sh` は変更しないでください
- 完了判定は外部の `.loop/verify.sh` が行います
